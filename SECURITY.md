# Security Policy

## Supported versions

The latest preview is supported with security fixes until a stable release policy is established.

## Reporting

Use GitHub's private vulnerability reporting for `hanzales/mcp-guardian-runtime`. Do not include real credentials, customer data, or weaponized public examples. Expect acknowledgement within seven days.

McpGuardian.Runtime is defense in depth. Transport authentication, tool correctness, OS isolation, and least-privilege credentials remain the host application's responsibility.
